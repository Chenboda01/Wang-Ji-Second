# Wang Ji Second

Single-player typing game with 10 progressive rounds.

Live site: https://chenboda01.github.io/Wang-Ji-Second/

## How to Play

1. Click **Start Game**.
2. Type the prompt exactly as shown.
3. Clear each round before the timer reaches zero.
4. Finish all 10 rounds to win.

## Rules

- The game has **10 rounds**.
- Difficulty increases as rounds progress.
- Mistakes deduct time from the countdown.
- You can configure mistake penalty in settings.

## Settings

- **Difficulty**: Easy / Normal / Hard
- **Mistake Penalty**: adjustable from **2 to 10 seconds**

## HUD

- Round
- Time Left
- Penalty
- Score
- Streak
- Best
- Mistakes

## Tech

- HTML
- CSS
- Vanilla JavaScript

## Run Locally

No build tools are required.

- Open `index.html` in a browser.

## Files

- `index.html` - page structure and controls
- `styles.css` - game styles and responsive layout
- `script.js` - gameplay logic, timer, scoring, and settings
